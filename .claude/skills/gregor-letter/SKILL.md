# Letter to Gregor

Inputs: the session writeup, previous letters in `correspondence/`, Gregor's last reply, and anything the user says Tiv wants this session (ask if unknown).

1. Copy `templates/letter.md`. Fill the header: in-game date, **elapsed time since the last letter**, current location and route.
2. **Recap**: what happened, in Tiv's voice (formal, scholarly, vain, curious; see `CLAUDE.md`). Not a transcript — what a scholar would report.
3. **Hypotheses**: concrete, falsifiable theories about enemies, mysteries and the way forward. This gives the DM a place to hint at next steps, so include the questions Tiv genuinely cannot answer.
4. **Research requests**: numbered, specific things Gregor should search in the Candlekeep archives. Answer or react to Gregor's previous reply.
5. Save as `correspondence/<YYYY-MM-DD>_letter-NN_tiv-to-gregor.md` (real date + sequence; keep the in-game date in the header). Gregor's replies are `..._gregor-to-tiv.md`; the user adds those.
6. End every letter with the full signature block: "— Tivwick Bramblequill / Scholar of Candlekeep / Researcher in Applied Positive-Energy Necromancy".
7. Never put private journal content in the letter, and keep Tiv's scheming deniable.
